# Comprehensive Index of Open-Source & Top AI Coding Tools

### 🛠️ Local Agent Harnesses (The Coding Loops)
* **[OpenCode](https://github.com)**: A terminal-native, model-agnostic agent harness that wraps arbitrary LLMs with a persistent shell execution tool, file I/O, and SQLite-backed workspace state.
* **[Claude Code](https://github.com)**: Anthropic's official terminal-first agent harness tuned for low-latency repository execution and model-native tool loops.
* **[Hermes Agent](https://github.com)**: An open-source operational agent runtime featuring a dedicated framework for custom tool harnesses and persistent memory structures.
* **[OpenClaw](https://github.com)**: A self-hosted autonomous agent built to coordinate files and trigger system-level tasks across native workspaces.
* **[Cline](https://github.com)**: An IDE-native agent harness extension implementing a headless CLI and embeddable workspace runtime for step-by-step terminal approvals.
* **[Aider](https://github.com)**: A git-native, terminal-based AI coding assistant that acts as a localized repository harness to make edits directly in your files.

### 🏗️ Agent Platforms & Multi-User Harness Environments
* **[OpenHands](https://github.com)**: A self-hostable agent platform and SDK that provides sandboxed Docker container isolation, multi-agent delegation, and an enterprise control plane.
* **[Cursor](https://cursor.com)**: An AI-first code editor that functions as an IDE-level harness environment, managing repository context indexing, file-diff streaming, and inline agent sessions.

### 🏭 Software Factories & Orchestration Fabrics
* **[LangGraph](https://github.com)**: A framework designed to construct cyclical multi-agent workflows, allowing software factories to process tasks entirely unattended (AFK) via stateful graphs.
* **[CrewAI](https://github.com)**: An automation system that structures squads of specialized AI agents into collaborative workspace pipelines to mimic a digital software assembly line.

### 📦 Model Providers & Local Model Runners
* **[Ollama](https://ollama.com)**: A local model provider and runtime framework used to bundle, run, and serve large language models directly on consumer hardware.
* **[Llama.cpp](https://github.com)**: An open-source, bare-metal inference engine providing optimal local model deployment with minimal setup dependencies.
* **[Claude](https://anthropic.com)**: Anthropic's flagship foundational model and conversational workspace assistant designed for code generation and multi-turn interaction.
* **[Pi](https://heypi.com)**: Inflection AI's fluid conversational assistant optimized for high-fidelity chat and supportive human-machine dialogue.

### 🌐 Inference Gateways & Proxies
* **[OmniRoute](https://github.com)**: An open-source routing gateway that acts as a central proxy to combine credentials from hundreds of model providers into a single endpoint.
* **[LiteLLM](https://github.com)**: A lightweight gateway proxy that maps multiple provider APIs (Anthropic, OpenAI, local) down to a standard format.

### 🖥️ Workspace Muxers & Execution Infrastructure
* **[Herdr](https://github.com)**: A workspace harness and background server that tracks agent execution persistently across separate Git worktrees and terminal screens.
* **[vLLM](https://github.com)**: A low-latency serving engine engineered to run high-throughput token production for model inference tasks.
* **[LangChain](https://github.com)**: An open-source development framework utilized to chain prompts, tool definitions, and memory systems together.
