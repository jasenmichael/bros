# jq

Addon app `lib/apps/addon/jq/config.yml`. Off until Enable on `/settings/apps`. `kind: apt`. Spec `jq`. The image build runs `apt-get install -y jq`.

There is no `bin`, `cli`, or `gui`. jq does not show under **Apps** on `/terminal` and does not show in the Apps drawer. After Enable it is only the `jq` binary in the Desktop image.

Hub: [Apps](/docs/apps).
