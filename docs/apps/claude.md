# Claude

Addon app `lib/apps/addon/claude/config.yml`. Off until Enable on `/apps`. `kind: run`. The install command is `curl -fsSL https://claude.ai/install.sh | bash`.

`bin` is `claude`. The `cli` interface is `claude`. That row shows under **Apps** on `/terminal` only while Claude is enabled. There is no window.

`kind: run` has no Check. Update writes a force stamp and rebuilds Desktop so that curl runs again. The Agents page runs this binary after **Approve implement** when Claude is the selected runtime.

Hub: [Apps](/docs/apps.md).
