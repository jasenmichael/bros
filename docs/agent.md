# Agent

There is no `/agent` page and no `/api/agent`. A request for `/agent` is a missing page. Chat at `/chat` is one direct completion. Bros does not run a tool loop on Chat.

The job board is [Agents](/docs/agents) at `/agents`.

A later cut can drive Chat tools through OpenCode or OpenHands. Bros does not embed the OpenHands SDK.

Tunneled sidecar APIs are separate from chat. See [Tunnel](/docs/tunnel).
